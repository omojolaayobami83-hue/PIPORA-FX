PIPORA FX

Smart Market Intelligence

PIPORA FX is a forex market analysis dashboard for educational purposes.

Features

- TradingView charts
- Multiple forex markets
- EMA 9 and EMA 21
- RSI indicator
- Market structure analysis
- Break of Structure (BOS)
- Possible Change of Character (CHoCH)
- Support and resistance
- Trade journal
- Twelve Data integration

Project Files

- "package.json" — Project configuration
- "server.js" — Backend server
- ".env" — Private API key configuration
- ".gitignore" — Protects private files from Git uploads
- "public/index.html" — Dashboard
- "public/style.css" — Dashboard styling
- "public/app.js" — Analysis logic

Installation

1. Install Node.js.
2. Open the project folder in a terminal.
3. Run "npm install".
4. Configure your Twelve Data API key.
5. Run "npm start".
